Created a responsive todo list web application using React.js, JavaScript, CSS, and HTML to manage everyday tasks effectively. The app allows users to add, edit, check off, and remove tasks with state management and dynamic updates in the UI.
Used Vite as the build tool for fast bundling and live reloading. Ensured code modularity with components and clean structure under a src/ folder. The project demonstrates skills in frontend development, component state & props, event handling, and user interaction design.
Deployed via standard web hosting (linkable via GitHub Pages or a hosting service) so it can be viewed live.
Key Technologies: React.js · JavaScript · CSS · HTML · Vite · Component-Based Architecture
